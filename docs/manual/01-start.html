HACCP Cloud 사용 매뉴얼 ①편

시작하기

이 편에서 배우는 것
  • 업체번호와 로그인 ID 로 HACCP Cloud 에 로그인하는 방법
  • 처음 로그인한 업체관리자가 꼭 해야 하는 최초 설정
  • 내 프로필, 결재 도장 이미지, 비밀번호를 관리하는 방법

로그인, 내 정보, 비밀번호 절은 업체의 모든 사용자가 쓰는 기능입니다. 관리자만 하는 일에는 관리자 전용 표시를 붙였습니다. 이 편은 사원에게 그대로 전달해도 됩니다.

1. 로그인하기

HACCP Cloud 는 업체마다 받은 업체번호 6자리와 개인 로그인 ID, 비밀번호로 로그인합니다. 업체번호는 업체관리자에게 확인하세요.

로그인 화면에서 세 칸 입력하기

업체번호 없이 로그인 화면을 열면 "업체번호와 로그인 ID, 비밀번호를 입력하세요." 라는 안내와 함께 입력 칸 세 개가 보입니다.

  1. 첫 칸에 업체번호 6자리를 입력합니다. 숫자만 6자리까지 들어갑니다.
  2. 둘째 칸에 로그인 ID를 입력합니다.
  3. 셋째 칸에 비밀번호를 입력하고 로그인 버튼을 누르거나 Enter 키를 누릅니다.

업체번호 주소로 로그인하기

주소창에 업체번호가 붙은 로그인 주소(예: /login/123456)로 들어오면 우리 업체의 이름과 로고가 보이고, 제목이 "(업체명)에 로그인" 으로 바뀝니다. 이때는 두 단계로 로그인합니다.

  1. 로그인 ID를 입력하고 다음을 누릅니다.
  2. "본인 확인을 위해 비밀번호를 입력하세요." 안내가 보이면 비밀번호를 입력하고 로그인을 누릅니다.

한 번 로그인하면 마지막으로 쓴 업체번호와 로그인 ID 를 기억해서 다음 로그인 때 미리 채워 줍니다. 다른 계정으로 들어가려면 아래 버튼을 씁니다.

  • 비밀번호 단계에서 다른 ID로 로그인: 같은 업체의 다른 ID 로 로그인
  • ID 단계에서 다른 업체번호로 로그인: 세 칸 로그인 화면으로 돌아가 다른 업체번호 입력
팁 업체번호가 붙은 로그인 주소를 브라우저 즐겨찾기에 등록해 두세요. 다음부터는 ID 가 미리 채워져 비밀번호만 입력하면 됩니다.

로그인하면 대시보드로 이동합니다. 대시보드 사용법은 ⑦편에서 다룹니다.

2. 처음 로그인하면: 업체 관리자 최초 설정 관리자 전용

업체관리자가 처음 로그인하면 대시보드 대신 업체 관리자 최초 설정 화면이 열립니다. 화면에는 "사용자 1명 이상과 부서 1개 이상을 생성한 뒤 초기 설정 완료를 진행하세요." 라는 안내가 보입니다.

주의 최초 설정을 끝내기 전에는 다른 메뉴로 이동할 수 없습니다. 다른 주소를 입력해도 이 화면으로 돌아옵니다.

화면의 "사용자 0 / 1", "부서 0 / 1" 은 지금까지 만든 수와 필요한 최소 수입니다. 두 숫자가 모두 1 이상이 되어야 설정을 끝낼 수 있습니다.

  1. 이름, 이메일, 부서를 입력하고 사용자 추가를 누릅니다. 부서 칸에는 처음에 "품질관리팀" 이 채워져 있으니 필요하면 고칩니다.
  2. 부서명을 입력하고 부서 추가를 누릅니다.
  3. 사용자와 부서가 모두 1 이상이 되면 초기 설정 완료 버튼을 누릅니다.
  4. "초기 설정이 완료되었습니다. 대시보드로 이동할 수 있습니다." 가 보이면 끝입니다.

여기서는 최소한만 만들면 됩니다. 부서, 사용자, 권한을 자세히 짜는 방법은 ②편에서 다룹니다.

3. 내 정보 관리

화면 오른쪽 위의 내 이름 버튼을 누르면 사용자 메뉴가 열립니다. 메뉴에는 내 정보 관리, 보안 설정, 로그아웃이 있습니다.

내 정보 관리를 누르면 프로필 이미지와 결재 서명/도장 이미지를 관리하는 화면이 열립니다.

프로필 이미지

  1. "프로필 이미지를 변경하려면 아바타를 클릭하세요." 안내 위의 아바타를 누릅니다.
  2. 이미지 파일을 고릅니다. 고르는 즉시 저장되고 "프로필 이미지가 저장되었습니다." 가 보입니다.

결재 서명/도장 이미지

등록한 이미지는 결재 문서의 결재선에 내 서명이나 도장으로 표시됩니다. 결재선은 ⑤편 기안 작성 화면에서 설명합니다. 서명과 도장은 이미지 하나로 관리합니다.

  1. 아직 등록하지 않았다면 "아직 등록된 이미지가 없습니다." 가 보입니다.
  2. 이미지 업로드를 누르고 서명이나 도장 이미지 파일을 고릅니다.
  3. "결재 도장 이미지가 저장되었습니다." 가 보이면 끝입니다.
주의 이미지 파일만 올릴 수 있고, 파일 크기는 2MB 이하여야 합니다.

이 화면의 이름, 이메일, 부서, 권한, 로그인 아이디는 볼 수만 있습니다. 바꿔야 하면 업체관리자가 사용자 관리 화면에서 바꿉니다(②편).

4. 비밀번호 변경

  1. 사용자 메뉴에서 보안 설정을 누릅니다. "비밀번호 변경" 화면이 열립니다.
  2. 현재 비밀번호를 입력합니다.
  3. 새 비밀번호와 새 비밀번호 확인에 같은 값을 입력합니다.
  4. 저장을 누릅니다. 그만두려면 취소를 누릅니다.
  5. "비밀번호가 성공적으로 변경되었습니다." 가 보이면 끝입니다. 입력 칸은 비워지고 로그인 상태는 그대로 유지됩니다.
비밀번호 규칙 새 비밀번호는 8자 이상이어야 하고, 현재 비밀번호와 달라야 하며, 확인 칸과 같아야 합니다.

5. 로그아웃

사용자 메뉴에서 로그아웃을 누릅니다. 마지막으로 쓴 업체번호의 로그인 화면으로 돌아갑니다.

주의 여러 사람이 함께 쓰는 PC 에서는 일을 마친 뒤 반드시 로그아웃하세요.

6. 안내 메시지 풀이

화면에 나오는 메시지뜻과 해결 방법
로그인 실패: 사용자 ID 또는 비밀번호를 확인하세요.업체번호, 로그인 ID, 비밀번호 중 틀린 것이 있습니다. 대소문자와 업체번호 6자리를 다시 확인하세요.
로그인 ID를 입력하세요.로그인 ID 칸이 비어 있습니다. ID 를 입력한 뒤 다음을 누르세요.
사용자 1명 이상, 부서 1개 이상이 필요합니다.최초 설정의 완료 조건이 아직 채워지지 않았습니다. 사용자 추가와 부서 추가를 한 번 이상씩 하세요.
초기 설정 진행 상태를 불러오지 못했습니다. 잠시 후 다시 시도해주세요.일시적인 연결 문제입니다. 메시지 옆 다시 시도를 누르세요.

이미지 파일 크기는 2MB 이하만 가능합니다.파일이 너무 큽니다. 크기를 줄인 이미지를 고르세요.
현재 비밀번호를 입력해주세요.현재 비밀번호 칸이 비어 있습니다.

새 비밀번호와 확인 값이 일치하지 않습니다.새 비밀번호와 새 비밀번호 확인 칸에 같은 값을 입력하세요.
현재 비밀번호와 다른 새 비밀번호를 입력해주세요.지금 쓰는 비밀번호와 다른 값으로 정하세요.
비밀번호 변경에 실패했습니다.현재 비밀번호가 틀렸거나 일시적인 오류입니다. 현재 비밀번호를 확인하고 다시 시도하세요.

비밀번호를 잊었어요

일반 사용자는 업체관리자에게 알리고, 업체관리자가 HACCP Cloud 플랫폼 담당자에게 초기화를 요청합니다. 업체관리자 본인이 잊었을 때도 플랫폼 담당자에게 문의하세요.
