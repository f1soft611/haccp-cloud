# [작업지시서] 부서 관리 리팩토링

## 1. 배경 및 목표
- 기존에 간단하게 구현된 부서 관리 페이지를 현재 프로젝트 구조 및 개발 패턴에 맞게 재구성
- 부서 관리를 **메뉴 관리와 동일한 패턴(UI/구조/개발 방식)** 으로 리팩토링

---

## 2. 작업 내용

### 필수 요구사항
1. **부모/자식 관계 기반 부서 등록**
   - 상위 부서를 선택하여 하위 부서 등록 가능
   - Root 부서 등록 가능
   - 부서 계층 구조 유지

2. **Tree Grid 형태 조회**
   - 등록된 부서를 트리 구조로 조회
   - 메뉴 관리 화면을 참고하여 동일한 UI/UX 적용
   - 부모/자식 관계 표시 및 Expand/Collapse 지원

---

## 3. 영향 범위

| 구분 | 내용 |
|---|---|
| Frontend | 기존 부서 관리 화면 수정, 메뉴 관리 패턴 기반 UI 및 데이터 처리 구조 적용 |
| Backend | Controller-Service-DAO 패턴 기준으로 서비스 구현, 프로젝트 API 규칙 준수 |
| Database | 기존 테이블 사용 (`tb_department`) |
