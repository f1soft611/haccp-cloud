업체관리자용

HACCP Cloud 사용 매뉴얼

업체관리자가 HACCP Cloud 를 처음 쓸 때 필요한 내용을 편으로 나눠 안내합니다. 완성된 편부터 순서대로 열립니다.

  1. ①시작하기 로그인, 첫 설정, 내 정보, 비밀번호
  2. ②조직 관리 부서, 권한, 사용자
  3. ③기준정보 공통코드, 품목, 거래처, 설비
  4. ④HACCP 양식관리 분류 설정, 업무(양식) 등록, 양식 편집
  5. ⑤문서 작성과 결재 기안 작성, 결재, 반려된 문서 다시 올리기, 지난 문서 찾기
  6. ⑥HACCP 관리 HACCP 문서포탈, HACCP 문서현황, 작업지시
  7. ⑦종합현황 상태 카드, 할 일 목록, 업무 캘린더
