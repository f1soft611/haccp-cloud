HACCP Cloud 사용 매뉴얼 ⑤편

문서 작성과 결재

이 편에서 배우는 것
  • HACCP 기록 문서를 작성하고 결재를 올리는 방법
  • 결재자와 참조자가 문서를 승인, 반려, 확인하는 방법
  • 반려된 문서를 고쳐 다시 올리고, 지난 문서를 찾는 방법

기안 작성과 결재는 업체의 모든 사용자가 쓰는 기능입니다. 관리자만 쓸 수 있는 기능에는 관리자 전용 표시를 붙였습니다. 이 편은 사원에게 그대로 전달해도 됩니다.

1. 한눈에 보는 결재 흐름

기본 흐름

기안 작성→ 저장 (임시저장)→ 결재 신청→ 검토 승인→ 최종 승인

반려되었을 때

반려→ 반려된 문서 열기→ 내용 수정→ 재결재 신청

참조자로 지정된 사람은 결재 진행과 별개로 문서가 도착하면 확인 처리를 합니다.

문서 상태

상태뜻할 수 있는 일
임시저장작성 중이고 아직 결재를 올리지 않은 문서내용 수정, 결재 신청, 삭제
결재진행중결재를 올려서 검토자나 승인자의 처리를 기다리는 문서작성자는 결재 취소, 첨부파일 추가. 결재자는 승인 또는 반려
승인최종 승인까지 끝난 문서조회
반려결재자가 반려해서 작성자에게 돌아온 문서내용 수정 후 재결재 신청

2. 기안 작성하러 들어가기

작성할 문서는 HACCP 양식관리에 정해 둔 업무와 등록주기(매일, 매주, 매월 등)에 따라 자동으로 할 일 목록에 올라옵니다. 양식을 만들고 등록주기를 정하는 방법은 ④편에서, 업무 캘린더 사용법은 ⑦편에서 다룹니다. 아래 세 곳 중 편한 곳에서 들어가면 같은 기안 작성 화면이 열립니다.

종합현황의 할 일 목록에서

  1. 로그인하면 처음 보이는 종합현황에서 할 일 목록을 확인합니다. "내가 작성해야 할 문서" 카드에서 작성할 문서 수를 볼 수 있습니다.
  2. 작성할 업무 줄의 작성하러 가기 버튼을 누릅니다.

종합현황의 업무 캘린더에서

  1. 메뉴의 종합현황을 열고 검색 영역 오른쪽 위의 캘린더를 누릅니다.
  2. 달력에서 작성할 업무 일정을 누릅니다. 이번 주기에 아직 작성하지 않은 업무는 오늘 칸에 있습니다.

HACCP 문서포탈에서 관리자 전용

문서포탈은 업무분류별로 모든 기록 문서를 한 번에 보는 관리자용 화면입니다.

  1. 메뉴의 HACCP 관리 > HACCP 문서포탈을 엽니다.
  2. 필요하면 업무분류, 등록주기, 구분명이나 담당자로 목록을 좁힙니다.
  3. 작성할 문서 줄의 작성하러 가기 버튼을 누릅니다.

3. 기안 작성 화면

기안 작성 화면은 다음 영역으로 나뉩니다.

영역내용
위쪽 버튼 줄저장, 결재 신청, 삭제, 돌아가기 등. 문서 상태와 내 역할에 따라 보이는 버튼이 달라집니다.
기본 정보기안 제목, 기안번호, 기안일, 기안자, 업무명, 업무 기준일. 기안번호는 결재 신청 시 자동으로 만들어집니다.
본문양식에 맞춘 기록 내용을 입력합니다.
결재선기안, 검토, 승인 세 칸에 담당자 이름과 처리 상태(승인, 확인, 반려, 대기)가 보입니다. 검토자와 승인자는 HACCP 양식관리에서 정해 둔 사람이 자동으로 들어갑니다.
참조결과를 함께 확인할 사람을 지정합니다. "참조자 이름으로 검색" 칸에 이름을 입력해 고릅니다.
첨부파일파일 선택으로 사진이나 서류를 올리고, 미리보기, 다운로드로 확인합니다.
결재의견결재자와 작성자가 의견을 주고받는 곳입니다. 의견을 입력하고 결재의견 등록을 누릅니다.

작성하고 결재 올리기

  1. 기안 제목을 입력합니다. 제목은 반드시 입력해야 합니다.
  2. 본문에 기록 내용을 입력합니다.
  3. 필요하면 참조자를 지정하고 첨부파일을 올립니다.
  4. 아직 다 쓰지 못했다면 파란색 저장 버튼으로 임시저장합니다. 나중에 다시 열어 이어서 쓸 수 있습니다.
  5. 작성을 마쳤으면 주황색 결재 신청 버튼을 누르고 확인 창에서 한 번 더 확인합니다.
주의 결재가 필요 없는 문서는 결재 신청 대신 저장 버튼만 보입니다. 이때 저장하면 바로 완료되고 이후에는 수정할 수 없으니, 내용을 다 확인한 뒤 저장하세요.

첨부파일

첨부파일은 문서가 한 번 저장되어 결재 문서가 만들어진 뒤에 올릴 수 있습니다. 처음 연 문서라면 먼저 저장하세요.

임시저장한 기안 삭제

  1. 임시저장 상태의 내 기안을 엽니다.
  2. 빨간색 삭제 버튼을 누르고 확인 창에서 삭제를 누릅니다.
주의 삭제한 기안은 복구할 수 없습니다.

4. 결재 신청 후

결재를 올리면 문서 상태가 결재진행중으로 바뀌고 본문은 잠깁니다. 단, 첨부파일은 결재 진행 중에도 추가로 올릴 수 있습니다.

결재 취소

결재를 올린 뒤 내용을 고쳐야 한다면 결재를 취소합니다.

  1. 결재진행중인 내 문서를 엽니다.
  2. 결재 취소 버튼을 누르고 확인 창에서 결재 취소를 누릅니다.
  3. 문서가 다시 수정 가능한 상태가 됩니다. 고친 뒤 다시 결재 신청을 누릅니다.

5. 결재자가 할 일

내 결재 차례가 된 문서는 종합현황의 "내 결재를 기다리는 문서"에서 확인하고 열 수 있습니다.

검토자와 승인자

  1. 문서를 열어 본문, 첨부파일, 결재의견을 확인합니다.
  2. 문제가 없으면 초록색 승인 버튼을 누릅니다. 검토자에게는 검토 승인, 마지막 승인자에게는 최종 승인으로 보입니다.
  3. 고칠 내용이 있으면 결재의견에 이유를 남기고 빨간색 반려 버튼을 누릅니다. 문서는 작성자에게 반려됩니다.
팁 반려할 때는 결재의견에 무엇을 고쳐야 하는지 적어 주세요. 작성자가 반려된 문서에서 바로 확인할 수 있습니다.

참조자

  1. 참조자로 지정된 문서를 엽니다.
  2. 내용을 보고 초록색 확인 버튼을 누릅니다. 마지막 확인자로 지정된 경우에는 최종 확인으로 보입니다.

6. 반려된 문서 다시 올리기

결재자가 반려한 문서는 작성자에게 반려됩니다. 대시보드의 "내가 결재 요청했으나 반려된 문서"에서 찾을 수 있습니다.

  1. 반려된 문서를 엽니다.
  2. 결재의견에서 반려 이유를 확인합니다.
  3. 내용을 고칩니다.
  4. 주황색 재결재 신청 버튼을 누릅니다. 처음 결재와 같은 순서로 다시 결재가 진행됩니다.

7. 지난 문서 찾기 (HACCP 문서현황)

이미 작성했거나 결재한 문서는 메뉴의 HACCP 관리 > HACCP 문서현황에서 찾습니다. 검색 조건과 목록 보는 법은 ⑥편 3. HACCP 문서현황에서 다룹니다.

8. 안내 메시지 풀이

화면에 나오는 메시지뜻과 해결 방법
결재 취소 후에 임시저장할 수 있습니다.이미 결재를 올린 문서입니다. 고치려면 먼저 결재 취소를 누르세요.
결재 취소 후에 결재신청할 수 있습니다.이미 결재가 진행 중입니다. 다시 올리려면 먼저 결재 취소를 누르세요.
기안 제목은 필수입니다.기안 제목 칸을 채운 뒤 다시 저장하거나 결재 신청하세요.
이 문서의 소유자가 아니므로 편집할 수 없습니다.다른 사람이 작성한 문서입니다. 조회만 할 수 있습니다.
문서 상태상 현재는 읽기 전용입니다.승인이 끝났거나 결재가 진행 중이라 수정할 수 없는 상태입니다.
결재 진행중 문서는 본문 편집은 잠겨 있지만 첨부파일 업로드는 가능합니다.결재 중에는 본문을 고칠 수 없지만 첨부파일은 추가할 수 있습니다. 본문을 고치려면 결재 취소를 누르세요.
결재 문서가 생성된 후 첨부파일을 업로드할 수 있습니다.처음 연 문서입니다. 먼저 저장한 뒤 첨부파일을 올리세요.
